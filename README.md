# Morrow Bakehouse

A responsive, single-page bakery landing page built with plain HTML, CSS, and a small amount of JavaScript.

## Run locally

Open `index.html` in a browser. The page uses Google Fonts and Unsplash-hosted photographs, so those assets require an internet connection.

## Before launch

Replace the Morrow Bakehouse concept name, sample bakery copy, and visit placeholders with the business's real details. Swap in original bakery photos when available.
